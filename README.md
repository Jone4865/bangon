<h1 align="center">뱅온 (BangOn)</h1>
<p align="center">좋아하는 스트리머의 방송을 한눈에.<br>치지직 · SOOP · 유튜브 · 트위치 채널을 화면 위 작은 덱에 모아두는 무료 앱 (macOS · Windows)</p>

<p align="center"><a href="https://bangon-app.vercel.app">홈페이지</a> · <a href="../../releases/latest">다운로드</a></p>

## 다운로드

| | 파일 |
|---|---|
| macOS 13 이상 (인텔 / M 칩) | [BangOn.dmg](../../releases/latest/download/BangOn.dmg) |
| Windows 10 / 11 설치형 | [BangOn-Setup.exe](../../releases/latest/download/BangOn-Setup.exe) |
| Windows 포터블 (설치 없이) | [BangOn-Portable.exe](../../releases/latest/download/BangOn-Portable.exe) |

처음 열 때 보안 경고가 나오면 — macOS: 앱을 **우클릭 → 열기** / Windows: **추가 정보 → 실행**

## 기능
- 방송 중이면 컬러, 꺼져 있으면 흑백 · 클릭하면 바로 방송으로
- 다른 앱·전체화면 위에도 항상 떠 있는 덱, 그리드·아이콘 크기 자유 설정
- 방송 시작 알림 · 멀티뷰 · 단축키 · 맥↔윈도우 설정 동기화 · 설정 내보내기/가져오기

모든 기능이 무료예요. 도움이 됐다면 [후원](https://toon.at/donate/ggyaaaaak)으로 응원해주세요 ☕
